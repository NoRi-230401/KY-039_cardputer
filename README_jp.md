# KY-039_cardputer
**[`English`](README.md)**

M5Stack CardputerとKY-039心拍センサーを使用して、心拍数（BPM）と心拍波形をリアルタイムで表示するアプリケーションです。

## 主な機能

*   **リアルタイム測定・表示:** 心拍数（BPM）と心拍波形をリアルタイムで測定・表示します。
*   **リアルタイム波形プロット:** センサーからのアナログ値をリアルタイムでグラフ描画します。グラフの縦軸は自動でスケール調整され、波形が見やすいように最適化されます。
*   **デュアル表示モード:** 用途に応じて2つの表示モードを切り替えられます。
    *   **プロットモード:** 心拍波形を大きく表示し、現在のBPM値を画面上部にコンパクトに表示します。
    *   **BPMモード:** BPM値を画面中央に大きく表示し、測定に集中できます。
*   **豊富な設定機能:**
    *   **画面の明るさ:** 0 (消灯) から 255 の範囲で細かく調整可能です。
    *   **低バッテリー警告:** バッテリー残量が指定したしきい値（5%～95%）を一定時間下回った場合に警告を表示し、自動でシャットダウンしてバッテリーを保護します。
    *   **言語切替:** 表示言語を日本語と英語で切り替えられます。
*   **設定の永続化:** 変更した設定は本体の不揮発性メモリ（NVS）に自動で保存され、次回起動時にも設定が維持されます。
*   **SDアップデーター対応:** 起動時に`a`キーを押すことで、SDカード上の`menu.bin`を起動できます。

## 必要な機材

*   M5Stack Cardputer
*   KY-039 心拍センサーモジュール

## 接続方法

KY-039センサーをCardputerのGroveポート（Port.B）に接続します。

| KY-039 | Cardputer (Grove Port.B) |
| :----: | :----------------------: |
|   S    |            G1            |
|  VCC   |           3.3V           |
|  GND   |           GND            |

## インストール

#### 方法1: SDアップデーターを使用する (推奨)
1.  本リポジトリの `BINS` フォルダにある `.bin` ファイルをSDカードのルートにコピーします。
2.  M5Stack-SD-Updater の `menu.bin` を使用して、SDカードからファームウェアを書き込みます。

#### 方法2: PlatformIO を使用する
1.  このリポジトリをクローンまたはダウンロードします。
2.  Visual Studio Code と PlatformIO 拡張機能をインストールします。
3.  プロジェクトを PlatformIO で開き、Cardputer を接続してアップロードします。

## 操作方法

### キー割り当て

| キー | 機能                                                              |
| :--: | :---------------------------------------------------------------- |
| `0`  | 表示モードを「BPMモード」と「プロットモード」で切り替えます。 |
| `1`  | 画面の明るさ設定モードに移行します。           |
| `2`  | 低バッテリー警告のしきい値設定モードに移行します。 |
| `3`  | 表示言語の設定モードに移行します。             |
| `;`  | **[設定モード中]** 値を大きく増やします。（上キー）                                  |
| `.`  | **[設定モード中]** 値を大きく減らします。（下キー）                                  |
| `/`  | **[設定モード中]** 値を小さく増やします。（右キー）                                  |
| `,`  | **[設定モード中]** 値を小さく減らします。（左キー）                                  |
| `` ` ``  | **[設定モード中]** 設定モードを終了し、通常モードに戻ります。（バッククォートキー） |

### 起動時オプション
*   **`a`キーを押しながら起動:** SDカード上の `menu.bin` を起動します。

## 技術的な詳細

### 心拍数計算
*   センサーからのアナログ値は、50Hzの電源ノイズを除去するために20ms周期で平均化されます。
*   さらに移動平均フィルタを適用し、ノイズの少ない滑らかな波形を生成します。
*   波形の上昇を検出し、心拍の間隔を計算します。
*   過去3回分の心拍間隔に重み付け平均（現在:0.4, 1回前:0.3, 2回前:0.3）を行い、安定したBPM値を算出します。
*   測定値の妥当性（波形の振幅、心拍間隔、BPMの急激な変化）を検証し、異常値を棄却することで信頼性を高めています。

### 省電力機能
*   本アプリケーションでは使用しないWi-FiとBluetoothを起動時に無効化し、消費電力を抑えています。
